# Personal Projects Portfolio Website

A modern, responsive personal Projects portfolio website showcasing software development projects, artistic work, and contact information for Jacob Mwambwa.

## Overview

This is a single-page portfolio website built with HTML5, CSS3, and vanilla JavaScript. It features a dual-theme (light/dark mode) design, modal dialogs for detailed information, and a clean, professional layout suitable for a developer and musician.

## Features

- **Responsive Design**: Adapts to desktop, tablet, and mobile screens
- **Dark/Light Theme Toggle**: Persistent theme preference using `localStorage`
- **Modal Dialogs**: Pop-up content for detailed bio and privacy policy
- **Project Showcase**: Live links to deployed web applications
- **Social Media Links**: Connection to various profiles (GitHub, YouTube, SoundCloud, etc.)
- **Contact Form**: Integrated with Formspree for message handling
- **Bootstrap 5**: Utility classes for quick styling
- **Font Awesome Icons**: Visual icons for links and buttons

## Tech Stack

| Technology | Purpose |
